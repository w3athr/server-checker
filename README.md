# server-checker
A lightweight command-line tool for automating post-deployment health checks on physical network appliances. It guides you through selecting your hardware model and software product, then lets you:

- Retrieve and validate system configuration (CPU, RAM, storage, NICs)
- Monitor real-time load (CPU/memory)
- Trigger LED tests on network ports and verify link connectivity at the MAC level
- Fill in compliance checkboxes and comments interactively

Finally, it generates a polished HTML report summarizing detected hardware, test results, and any discrepancies—ideal for validating pilot installations and producing audit-ready documentation.
